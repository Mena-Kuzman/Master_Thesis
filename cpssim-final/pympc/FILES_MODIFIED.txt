HOW TO USE
================================================================

1. Enable the feature:
   cfg.simulation_params['terrain_adaptive_step_height_enabled'] = True

2. Run tests to verify:
   python test_terrain_adaptive_step_height.py

3. Test on varied terrain:
   - Flat ground (baseline verification)
   - Slopes (uphill/downhill)
   - Rough surfaces (obstacles)
   - Variable terrain (transitions)

4. Adjust sensitivity if needed (optional):
   cfg.simulation_params['swing_pitch_sensitivity'] = 0.5 to 1.0
   cfg.simulation_params['swing_roughness_sensitivity'] = 0.5 to 1.0
   cfg.simulation_params['swing_velocity_sensitivity'] = 0.1 to 0.5
